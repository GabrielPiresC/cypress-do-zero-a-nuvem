# 🌲 Cypress, do Zero à Nuvem ☁️

[![en](https://img.shields.io/badge/lang-en-red.svg)](README.en.md)

Projeto de exemplo para o curso "Cypress, do Zero à Nuvem" da escola online Talking About Testing.

## Pré-requisitos

É necessário ter git, Node.js e npm instalados para clonar e executar este projeto.

> Utilizei as versões `2.54.0`, `v24.15.0` e `11.12.1` de git, Node.js e npm, respectivamente. Sugiro que você utilize as mesmas versões LTS ou versões mais recentes.

## Instalação

Execute `npm install` (ou `npm i`, a versão abreviada) para instalar as dependências de desenvolvimento.

## Testes

Neste projeto, você pode executar os testes em uma viewport de desktop ou de dispositivo móvel (mobile).

### Desktop

Execute `npm test` (ou `npm t`, a versão abreviada) para rodar o teste em modo *headless* em uma viewport de desktop.

Ou execute `npm run cy:open` para abrir o Cypress App em uma viewport de desktop.

### Mobile

Execute `npm run test:mobile` para rodar o teste em modo *headless* em uma viewport de dispositivo móvel.

Ou execute `npm run cy:open:mobile` para abrir o Cypress App em uma viewport de dispositivo móvel.
